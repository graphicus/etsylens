Why not just use a SaaS tool?

Tools like ListingView.io charge a recurring fee for a workflow that's really four repeatable lookups. Their edge is a proprietary database built from continuously crawling 130 million-plus listings — genuinely useful at scale, and genuinely unnecessary if you're checking your own listings or scouting a handful of competitors on demand.

EtsyLens fetches the same information live, straight from Etsy's public pages, the moment you ask for it. No database to maintain, no seat to pay for.

Built in the open, with AI doing the typing

The scraping logic, SEO scoring model, and this page were all built through conversational iteration with Claude — describing what each module should do and reviewing the code as it came together, rather than writing it line by line.

One honest limitation

Etsy blocks scraping requests from cloud and datacenter IP ranges — AWS, GCP, Render, all of them — at the network level. That means the live demo above can't always pull real data from where it's hosted.

Rather than show a raw error, the app detects the block and falls back to clearly-labeled sample data, so every feature stays fully explorable. Clone the repo and run it on your own connection, and it scrapes real, live Etsy data with no changes needed.
